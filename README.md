# Sales Analytics Dashboard

A sales analytics dashboard for a fictional online store, with data on customers, products, orders and payments.

## Stack

- PostgreSQL (or MySQL)
- Next.js (App Router)
- TypeScript
- SQL (aggregation queries)
- Charts (e.g. Recharts / Chart.js)

## Data model

- Customers
- Products
- Orders
- OrderItems
- Payments

## Data flow

Database -> SQL -> API -> Data processing -> Dashboard

## Dashboard features

- [ ] Revenue
- [ ] Orders
- [ ] Average order value
- [ ] Best-selling products
- [ ] Sales by month
- [ ] Sales by category
- [ ] Customer statistics
- [ ] Date filters

## What this project demonstrates

SQL + databases + data analysis + dashboards
